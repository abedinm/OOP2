# OOP2 course materials

CSC 3115 Object Oriented Programming 2 — lecturer Saikat Baul (saikatbaul@aiub.edu).
Slides and example code shared by the instructor.

## Slides

| Week | File | Topics |
|------|------|--------|
| 1 | `slides/OOP2-Lecture-Week-01.pptx` | Course orientation: outline, books, evaluation, class and grading policies |
| 2 | `slides/OOP2-Lecture-Week-02.pptx` | C# basics: data types, type casting, `readonly`/`const`, structures, enumerations, strings, `params`/`ref`/`out`, class and object, constructors, variable types |
| 3 | `slides/OOP2-Lecture-Week-03.pptx` | Properties, OOP principles, encapsulation, arrays |

## Code examples (`codes/`)

Each folder is a .NET Framework 4.7.2 console app. Open the `.slnx` file in Visual Studio 2022.

| Example | Goes with |
|---------|-----------|
| `C_1stCode` | Week 2 — first C# program |
| `Basic_operation` | Week 2 — data types, operators, type casting |
| `Structt` | Week 2 — structures |
| `enum` | Week 2 — enumerations |
| `param`, `ref_out` | Week 2 — `params`, `ref`, `out` |
| `class_object` | Week 2 — class and object |
| `Constructor_all` | Week 2 — constructors |
| `Access_Modifier` | Week 3 — access modifiers |
| `Properties` | Week 3 — properties |
| `Encapsulation` | Week 3 — encapsulation |
| `Jagged_array` | Week 3 — arrays |

`codes/output.txt` is a combined practice snippet (`ref`, `out`, `params`, enum, private field + getter).

In the Windows VM these are at `Z:\course-materials\`.
